# Screenshots

The main README embeds the images below. Capture each one and save it here with the
exact filename — no other changes needed.

| Filename | What to capture |
|---|---|
| `feed.png` | Home feed with a few posts visible, sort tabs in shot |
| `post.png` | A single post page with comments and reactions |
| `identity.png` | The identity panel — address, nickname, recovery string (**blur or regenerate the recovery string before sharing**) |
| `admin-moderation.png` | Admin moderation queue showing NSFW scores |
| `admin-ledger.png` | Admin Ledger Monitor after a successful chain verification |
| `admin-dashboard.png` | Admin dashboard overview |

Tips:
- Capture at a consistent width (1440px works well) so the README grid stays even.
- Use seeded/demo content — never real user uploads.
- On Windows: `Win + Shift + S`, or `F12` → device toolbar → capture screenshot for full-page shots.
